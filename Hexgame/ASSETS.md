# Recursos externos

Los modelos auxiliares de `Hexgame/assets/` provienen del paquete gratuito **Gobkit Nature Pack** de Ariescar y se distribuyen bajo licencia **CC0 1.0**.

Repositorio de origen: https://github.com/Ariescar/gobkit-free-assets

Archivos utilizados:

- `tree-tall.glb` — `NaturePack/Models/GLB/TreeHigh001.glb`
- `tree-round.glb` — `NaturePack/Models/GLB/TreeMed002.glb`
- `rock.glb` — `NaturePack/Models/GLB/Rock002.glb`
- `bush.glb` — `NaturePack/Models/GLB/Bush001.glb`
- `reeds.glb` — `NaturePack/Models/GLB/Reed001.glb`
- `cloud.glb` — `NaturePack/Models/GLB/Cloud001.glb`

El sonido del juego se sintetiza en tiempo real con Web Audio API y no utiliza archivos de terceros.
