# Castorium · Ajuste del conductor

Editor 3D pequeño y autocontenido para colocar `models/castorv2.glb` sobre `models/yale.glb`, reproducir `anim/Driving.fbx` y exportar una configuración de posición, rotación y escala.

## Uso

1. Servir el repositorio completo mediante HTTP; no abrir `index.html` como archivo local.
2. Abrir `/castor-driver-editor/`.
3. Ajustar el castor con el gizmo o los campos numéricos.
4. Copiar el bloque **Texto para pegar** y enviarlo en el chat.

El editor intenta cargar `anim/Driving.fbx` automáticamente. Si el archivo todavía no está en el repositorio, se puede elegir un FBX local desde el panel **Archivos**.

Los valores se guardan automáticamente en el navegador. **Restablecer** vuelve a posición y rotación cero con escala 1.
